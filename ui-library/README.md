# コタマ UI素材ライブラリ 第1弾

公開レビュー用のオリジナル候補。ゲームへの正式採用は未承認。原本は編集可能なSVGで、ゲーム用SVGとしても利用できる。素材のID・用途・寸法・SHA256は manifest.json。作品固有画像や外部素材の複製は収録しない。

- 方針は開発ブランチのカートグラフィーUIの暗い紺と古金を踏襲し、編成画面の青緑と接続。文字は素材に含めない。
- ボタンには通常・ホバー・押下・選択・無効の差分を収録。HTML側で状態を切り替える。
- ゲージは背景と充填SVGを重ね、充填SVGのみ clip-path で残量に合わせて切り抜く。
- 会話枠の独立レイヤーには border-image-slice 28 を使用できる。マップ記号はプレイヤー配置用の独立素材。
- PNGは検証Actionsの成果物で確認できる。恒久保存のSVGから再生成できる。
